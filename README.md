# 倒班助手（SwiftUI 源码原型）

这是一个原生 SwiftUI iOS 工程，目标是提供本地倒班日历、循环排班、班次编辑、班前本地通知、月度统计、同事名单和 JSON 备份/恢复。

## 当前包含

- 月历网格，彩色显示白班、夜班、休息和其他班次
- 按循环规则自动推算班次，支持上一休一、上二休二、白夜休等示例循环
- 单日班次编辑、备注、恢复自动排班
- 白班/夜班时间设置，支持跨午夜夜班
- 多个班前通知规则，滚动安排未来 21 天的本地通知
- 月度工作天数、休息天数、白班和夜班统计
- 本地同事名单
- JSON 备份和导入
- 无广告 SDK、无账号、无云端依赖

## 重要限制

1. 这是源码原型，尚未在此环境中使用 Xcode 编译、签名或真机测试。请先在 Xcode 中构建并处理可能的 SDK/版本兼容问题，再用于日常排班。
2. iOS 本地通知不等同于系统时钟的强制闹钟；通知权限、专注模式、静音和系统调度可能影响提醒。
3. 通知目前滚动安排未来 21 天。若你在后台长期不打开应用，建议启动应用时刷新通知；正式版可加入后台刷新和更稳妥的通知数量管理。
4. “四班三运转”提供的是示例循环，并不代表所有单位的实际排班。请在使用前确认本单位排班规则和起始日期。
5. 同事模块只是本地名单，不提供跨设备同步、共享排班或聊天。
6. “工资计算”、Widget 桌面小组件、锁屏实时活动、iCloud 同步等尚未实现。

## 在 Mac 上打开

1. 安装 Xcode。
2. 打开 `ShiftAssistantComplete.xcodeproj`。
3. 选择一个 iOS Simulator 或连接的 iPhone 作为运行目标。
4. 在 Signing & Capabilities 中选择自己的开发团队（安装到真机通常需要签名）。
5. Build & Run。生成 IPA 需要在 Xcode 中完成 Archive/Export 或使用相应签名流程。

## 建议测试清单

- 设置一个已知班次日期，核对前后至少 2 个周期的自动排班
- 检查夜班结束时间跨午夜
- 逐日修改班次后检查通知是否重新安排
- 导出 JSON 后清空测试数据，再导入验证
- 在真机允许通知后检查提醒时间和声音设置
